团子大决战官方游戏包

玩法：选人 → 押注 → 自动战斗 → 结算；记录连续押胜。

目录说明：
- manifest.json: 包描述、入口、窗口参数
- code/: Python 运行时代码（dango_showdown_pkg）
- assets/dango/: 每个团子的常态/攻击/受击素材，目录名与 roster.py 的 character_id 一致
- assets/effects/: 激光、虚手、星爆、水印、黄/青日灵、绯雪刀与花瓣素材；不依赖源码工作区路径
- 粒子与图片特效复用桌宠已有注册表；manifest 的 particles/effects 扩展列表为空

扩展团子：在 code/dango_showdown_pkg/roster.py 追加 DangoEntry，并放入对应素材目录即可。

西格莉卡「双色日灵」：有效团子碰撞攻击必获得能量，每次真实撞墙另有50%概率获得；共享四格，未满时添加一枚随机黄/青能量，两色等概率。满槽后再次成功获得能量不添加或覆盖颜色，改为将黄色、青色此刻正在冷却的日灵CD各减1秒，最低零；失败墙不减CD，未满时也不减CD。两枚同色且该色冷却为零时自动消耗并召唤，黄色和青色各自独立冷却五秒；满槽减到零会立即检查并召唤，新开的五秒CD不被同一次获得能量重复扣减。冷却期间能量保留，冷却到期会自动检查召唤。
黄色日灵对应原日灵1，青色对应原日灵2；固定在敌人被召唤时的位置，一秒后半径0.162范围爆炸28点。青色再隔0.45秒以半径0.27二次爆炸14点；半径以决斗区边长为1，目标离开范围可躲避。
日灵由纯规则层固定步长计时与判伤；暂停、开局倒计时及结算不推进，逐轮重置。

绯雪「霜渐环斩」：每3秒以自身为中心挥斩一圈，半径0.22，命中造成30伤害并使对手移动速度降低50%，持续3秒；再次命中刷新时长，不叠乘。未命中积攒1点霜渐能量，上限4点；每次有效身体碰撞消耗1点，令本次普通攻击额外造成2伤害。技能伤害不消耗霜渐能量，逐轮重置。
刀光使用绯雪刀原图及桌宠smooth_image_show的共享旋转/环绕，约0.06秒完成整圈瞬斩，随后白青余辉、宿主共享飘散雪花与少量红粉花瓣消散。绯雪生命经隐藏基准独立对战校准为165，保持5的倍数；当前值以包内code/dango_showdown_pkg/roster.py为准。

反馈实现：伤害数字与爆裂粒子使用桌宠既有粒子脚本，图片效果使用既有smooth_image_show；通过共享FeedbackScene在场内绘制、裁剪，暂停与关闭由本局场景管理，不向桌面覆盖层发送场内反馈。星爆GIF由共享图片效果支持动画取帧。
激光保留蓝到粉的渐变；解码时对静态贴图着色，原素材不改动，播放仍使用smooth_image_show与既有star_streak流光。
音效使用桌宠GameSfx现有cue与SOUND_REQUEST播放通道；包内只保存语义到cue的映射，不生成独立WAV或新波形，音色随共享目录统一。

这个目录本身就是一个可安装游戏包的解压态。
