异步高性能运算与异步请求任务规划

目标
- 保持 Qt 主线程只负责 UI、状态提交、轻量事件调度。
- 将重运算统一迁移为“快照采集 -> 后台计算 -> 主线程应用”模型。
- 将下载 / HTTP / 子进程探测统一迁移为“任务槽 + 线程池/进程池”模型。
- 避免在 FRAME/TICK 订阅链路中直接执行重计算、阻塞 I/O 或重复系统调用。

总原则
- QWidget/QPixmap/QPainter/QtMultimedia 主调用必须留在主线程。
- 后台任务只处理纯数据，不直接操作 Qt 对象。
- 高频任务必须 single-flight，不允许队列堆积。
- 下载/搜索/探测类请求优先 io_pool。
- numpy/cv2/可释放 GIL 的高频计算优先 vector_pool。
- 纯 Python 重 CPU 运算优先进程池或受控线程池。

验收标准
- 主线程中不再出现高频重复 COM/系统调用。
- 同一入口重复触发时不再堆积裸线程。
- 高频任务旧结果自动丢弃或合并。
- 网络/下载链路能被统一取消、复用、观测。
- 先通过静态编译，再做运行态帧耗时观察。
