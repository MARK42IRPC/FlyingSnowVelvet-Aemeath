# 代码结构整改清单

更新时间：2026-08-30

本文档记录当前有效的 `lib/core`、`lib/script` 与独立目录整改。源码和测试仍是最终事实源；完成项用于说明已经建立的边界，不代表可删除其回归测试。

## 整改原则

- `lib/core` 只保存协议、运行时、后端适配和可复用基础设施，不直接构造产品页面、业务管理器或资源专用声音。
- `lib/script` 保存产品组合、页面、插件、游戏、办公、音乐及具体资源行为。
- `config/`、`services/`、`install_deps/`、`scripts/`、`pyncm/`、`native/`、`resc/`、`tests/` 和 `doc/` 保持独立职责。
- 目录迁移必须同步静态导入、动态导入、发布白名单、文档和测试，不保留无调用方的兼容壳。

## P0 依赖方向

- [x] 解除 `qt_bridge/tray_icon.py` 与 `script/ui/ai_settings_panel.py` 的双向依赖；设置页通过业务服务读写开机启动状态。
- [x] 将 Qt 应用 UI 生命周期、主宠产品控件组合、托盘产品实现和工作台 helper 入口归入 `lib/script`。
- [x] Qt/DX 主宠窗口通过构造工厂取得状态机、启动声音和交互声音，不再由 `lib/core/pet_window.py` 导入业务实现。
- [x] Qt/DX 粒子与特效覆盖层通过管理器注入，不再从核心后端导入脚本管理器。
- [x] 为上述边界增加静态导入审计，阻止 `lib/core` 再次依赖 `lib.script`；启动组合入口是唯一允许的显式例外。

## P1 资源归属

- [x] 将 `lib/core/voice` 中的角色、对象和游戏专用声音迁移到 `lib/script/voice`。
- [x] `lib/core/voice` 只保留通用音频通道和目录随机声音能力。
- [x] 更新桌面对象、游戏包、UI 和主宠调用方，并检查发布包同时包含新路径。

## P2 稳定边界

- [x] 保持 `lib/core/dsh_runtime_contract.py` 与 `lib/core/voice_runtime_contract.py` 原位。本轮不迁移跨进程契约，避免同时改变安装器、侧车和运行时协议。
- [x] 保持官方游戏源码位于 `lib/script/gemes/packages/official/`，继续由发布脚本生成 `gamepack/official/*.zip`。
- [x] 保持安装器拆分在 `install_deps/`，根目录 `install_deps.py` 仅作为入口。

```powershell
py -3 scripts/package_release.py --dry-run --version LTS1.0.7beta2
py -3 scripts/package_green_release.py --dry-run --version LTS1.0.7beta2
git diff --check
```

额外静态验收：扫描 `lib/core/**/*.py` 的绝对与相对导入，除启动组合入口外不得出现指向 `lib.script` 的依赖；扫描旧模块路径不得存在活动引用。
