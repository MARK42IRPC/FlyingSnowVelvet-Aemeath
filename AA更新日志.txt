飞行雪绒 LTS1.0.6beta2 更新日志
==========================

版本发布日期：2026-06-27
本条目按 `2026-06-12` 至 `2026-06-27` 最近一轮推送整理，覆盖 `beta1` 之后的主要更新。

一、本次更新重点
----------------
1. 启动/退出序列帧动画模块重构。
   - `SEanima` 拆分为动画定义、帧解码、特效处理三层。
   - 设置面板新增启动/退出动画目录下拉框，可直接选择 `resc/GIF` 下的 `*_anima` 文件夹。
   - 默认启动动画为 `耶比_anima`，默认退出动画为 `爱弥斯联合_anima`。

2. 动画资源目录规范化。
   - 原 `start-anim-compressed`、`exit-anim-compressed` 已迁移到 `*_anima` 命名。
   - 播放器内部保留兼容回退，不改变外部启动/退出动画触发方式。

3. 外部 API 配置进一步脱敏。
   - `API Key`、`API_BASE_URL`、`API_MODEL` 全部改为写入 `resc/user/ai/ollama_secrets.json`。
   - `config/ollama_config.py` 不再保留这三项的明文用户值，降低误提交风险。

4. 安装器与本地配置保留逻辑继续修正。
   - Windows 下 Python 探测与调用链路进一步稳定。
   - 安装/修复流程更注意保留已有本地 AI secrets，减少重装后配置丢失。

5. 本地默认内容继续调整。
   - 同步更新部分默认配置和人格文本，使新装环境更贴近当前版本预期。
